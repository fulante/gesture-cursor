# Reference copies for a self-contained iteration-report folder.

These files are copies from the project root at delivery time:

- `CHANGELOG.md` — detailed version history
- `ITERATIONS.md` — project iteration log
- `BACKLOG.md` — remaining product/engineering issues
- `DEPLOYMENT.md` — environment, camera and tuning guide
- `legacy-SNAPSHOT.md` — original pre-v1.1 snapshot description

The authoritative project copies remain at the repository root; these are
included so the report folder can be read on its own.
